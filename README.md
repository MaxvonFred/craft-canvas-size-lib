# craft-canvas-size-lib

Canvas sizes and safe zones for the Craft apps, published by the platforms
themselves and kept in one place, so they are easy to review, correct and
extend.

Every size is grouped by **channel** (Social, later Print…), **platform**
(Instagram, TikTok…) and **type** (Stories, Feed portrait…). Every value links
to the platform's own spec page. A **safe zone** is the part of an image that
a platform's interface leaves visible; apps can draw it over the canvas.

Apps import one generated file, [`canvas-sizes.json`](canvas-sizes.json). The
tables below are generated from the same specs.

## Layout

```
specs/
  <channel>/
    channel.json              { "name": "Social", "order": 1 }
    <platform>/
      platform.json           { "name": "Instagram", "order": 1 }
      <type>.json             one size
safe-zones/
  <safe-zone>.json            one safe zone, referred to by its file name
scripts/build.ts              writes canvas-sizes.json and the tables below
```

A type file:

```json
{
  "name": "Stories",
  "order": 2,
  "width": 1440,
  "height": 2560,
  "safeZones": ["meta-stories-reels"],
  "source": "https://www.facebook.com/business/ads-guide/update/image/instagram-story"
}
```

Its id is `<platform>-<type>` from the folder and file names, here
`instagram-stories`. `safeZones` lists the safe zones made for the size, the
default first; each must have exactly the size's aspect ratio.

A safe zone keeps the numbers in the units the platform publishes them in, so
they can be checked against the source: `frame` is the template's size in
pixels, or `[100, 100]` for percent. `margins` say how far the interface reaches
in from each edge, and `covered` lists areas inside the margins that it covers
too, such as TikTok's button column, in a left-to-right layout. Apps mirror a
safe zone for right-to-left languages.

## Adding or correcting a size

1. Add or edit the JSON file. Link the platform's own spec page in `source`,
   not a blog or a template site.
2. Run `node scripts/build.ts` (Node.js 22.18 or newer; there are no
   dependencies to install). It checks every spec, reports all problems at
   once, and rewrites `canvas-sizes.json` and the tables below.
3. Commit the spec and both generated files together.

`node scripts/build.ts --check` fails when the generated files are out of date,
and `node --test scripts/build.test.ts` runs the tests.

## Safe zones

Margins and covered areas are in the units the platform publishes them in: the pixels of its template, or percent.

| Safe zone                | Ratio | Units          | Top | Right | Bottom | Left  | Also covered         | Source                                                                                   |
|--------------------------|-------|----------------|-----|-------|--------|-------|----------------------|------------------------------------------------------------------------------------------|
| Meta Stories & Reels     | 9:16  | percent        | 14% | 6%    | 35%    | 6%    | –                    | [facebook.com](https://www.facebook.com/business/ads-guide/update/image/instagram-story) |
| TikTok                   | 9:16  | 720 × 1280 px  | 160 | 80    | 440    | 80    | x 520–640, y 560–840 | [ads.tiktok.com](https://ads.tiktok.com/help/article/tiktok-auction-in-feed-ads)         |
| TikTok with product link | 9:16  | 540 × 960 px   | 126 | 60    | 406    | 60    | x 420–480, y 200–554 | [ads.tiktok.com](https://ads.tiktok.com/help/article/tiktok-auction-in-feed-ads)         |
| YouTube channel banner   | 16:9  | 2048 × 1152 px | 407 | 406.5 | 407    | 406.5 | –                    | [support.google.com](https://support.google.com/youtube/answer/10456525)                 |

- **Meta Stories & Reels.** Meta publishes these margins in percent, the same for Instagram Stories, Instagram Reels and Facebook Stories. Reels ads with a disclaimer need the bottom 40% clear: https://www.facebook.com/business/help/980593475366490
- **TikTok.** Measured from TikTok's 2025 In-Feed template without an anchor, which is drawn at 720 × 1280. The covered area is the like, comment and share column. TikTok's Arabic (RTL) template is the exact mirror image.
- **TikTok with product link.** Measured from TikTok's 2021 In-Feed template for ads with an anchor (a product link), which is drawn at 540 × 960, in its version for a one-line caption. Captions of two to four lines need a bottom margin of up to 507. TikTok's Arabic (RTL) template is the exact mirror image.
- **YouTube channel banner.** YouTube gives a 1235 × 338 safe area, centred, at the minimum upload size of 2048 × 1152: (2048 − 1235) / 2 = 406.5 and (1152 − 338) / 2 = 407.
